# Projet Google Traduction

## 📌 Description

Dans ce projet, l'objectif est de créer une application qui fait la traduction d'un texte d'un langage à un autre.

## 🔥 Installation 

```bash
git clone https://github.com/Mouhamed1000/Projet-Google-Traduction.git
cd Projet-Google-Traduction
```
